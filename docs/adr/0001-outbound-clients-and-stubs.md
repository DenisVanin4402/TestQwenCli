# ADR-001. Исходящие клиенты и заглушки

**Статус:** Принят. **Редакция:** 05.10.2026. Решение задаёт целевую архитектуру; готовность реализации подтверждается отдельно.

## Причина

Локальный сценарий должен запускаться без банковских систем, а подключение настоящего транспорта не должно менять бизнес-логику. Достаточно прикладного порта и его адаптера; слои только для переадресации вызова не нужны.

## Решение

- HTTP API и DTO внешних сервисов генерируются из OpenAPI через Maven стандартным генератором, без собственных Mustache-шаблонов. Транспорт — Spring Cloud OpenFeign, преобразование внутренних данных — MapStruct по [ADR-004](0004-api-domain-mapstruct.md). Обычный интерфейс InvestCorrHttpApi с @FeignClient наследует сгенерированный контракт без дублирования методов и подключает локальную конфигурацию corr.
- Имя клиента, адреса, транспортные тайм-ауты, настройки доступа и выбор реального клиента либо заглушки задаются конфигурацией. Для corr application.yaml задаёт integrations.invest-corr.name/url; индивидуальные настройки Feign и их проверка используют это имя. Секреты не вшиваются в код. Заглушка реализует тот же используемый контракт, не создаёт второй бизнес-сценарий.
- Для corr прикладная граница — `WorkflowManager.callOperation(Operation, OperationContext)` по [ADR-013](0013-outbound-retry-and-timeouts.md). Action вызывает её один раз. Временный адаптер преобразует контекст и делает один вызов существующего `submitStatus`; автоматических повторов нет. Обёртки вокруг прежнего SubmitStatusPort не требуются: старый путь удаляется.
- `void` означает отсутствие бизнес-результата операции для агента, а не подавление исключений. Ошибка передаётся транзакционной границе; её нельзя превращать в успешный UNCERTAIN.
- В POC реализуется только STATUS. Заглушки RECALL/DETAILS, будущий outbox, таймеры и УСС сейчас не создаются.
- По выбранному 05.10.2026 варианту A [task03](../tasks/task03/arch_design.md) технический клиент GigaChat переносится в текущий этап POC/тестового UI: штатная автоконфигурация `ai-forever/spring-ai-gigachat` и синхронный `ChatClient`, явное включение независимо от БД/corr. Самодельный HTTP/OAuth-клиент, OpenAPI-генерация этого API и обёртки для переадресации не нужны. Дизайн реализации и задачи явно согласованы 05.10.2026; реализация и независимая [валидация task03](../tasks/task03/validation.md) завершены. Роль модели и отдельная политика попыток заданы [ADR-007](0007-llm-responsibilities.md).
- Профиль БД и выбор stub/real клиента независимы. Отсутствующая обязательная конфигурация реального клиента не должна незаметно включать заглушку.

## Проверка и замена прежнего решения

Проверяются mapping, один фактический HTTP-вызов corr и передача ошибки без повтора; локальный запуск проверяется с заглушкой. Реальная интеграция требует проверки предоставленного внешнего контракта.

Общие retry-обёртки для всех клиентов, возврат corr-исходов в FSM и обязательная цепочка однотипных портов больше не требуются. Версии библиотек выбираются по совместимости проекта, а не обновляются ради этого ADR.
