# ADR-004. API, внутренняя модель и подготовка ответа

**Статус:** Принят. **Редакция:** 05.10.2026. Учитывает уточнение пользователя об ответственности Action и общего оркестратора.

## Причина

Один бизнес-сценарий обслуживает входящие каналы. Знание ACL, транспорта и текстов ответа не должно проникать в FSM или дублировать выбор переходов.

## Решение

Внешние API-интерфейсы и DTO генерируются из OpenAPI YAML Maven-фазой `generate-sources` в `target/generated-sources`. Используется стандартный механизм описаний summary/description без собственных Mustache-шаблонов. Generated-код не редактируется вручную и не копируется в исходники. Привязка сгенерированного интерфейса corr к @FeignClient находится в обычном исходнике; имя и адрес берутся из application.yaml. Исключение из генерации API — библиотечный GigaChat по [ADR-001](0001-outbound-clients-and-stubs.md). MapStruct выполняет структурный mapping на границах, не выбирает бизнес-переходы.

| Участник | Ответственность |
|---|---|
| Controller и входной адаптер | HTTP/ACL-валидация и корреляция, mapping во внутреннюю команду, вызов общего use case. Невалидный транспортный запрос не требует запуска FSM. |
| SessionTurnOrchestrator | Связывает вход с инфраструктурой исполнения. После её завершения получает предметный результат, выбирает и заполняет шаблон, возвращает подготовленный ответ без generated DTO. |
| FSM guards/actions | Выбирают допустимый переход и исполняют бизнес-действие; возвращают предметный исход и типизированные данные. Не знают текстов, шаблонов, GA или HTTP. |
| Адаптер ответа | Преобразует подготовленный ответ в протокол канала. Для GA задаёт адреса, корреляцию, status_code, performative и final_message. Controller передаёт ответ HTTP-слою. |
| Исходящий адаптер | Преобразует OperationContext в DTO corr и выполняет контракт WorkflowManager по ADR-013. |

Выбор и заполнение шаблона происходят **вне FSM, после рабочей транзакции**. Для POC достаточно локальных шаблонов/обычного форматирования в оркестрации; универсальный шаблонизатор, реестр в БД и LLM не нужны. Общий helper допустим при реальном переиспользовании, но не является обязательным слоем.

Сводка строится по возвращённому снимку конкретной подготовки, без повторного чтения изменяемого черновика. В native ExtendedState сохраняются подготовка, согласие и последний предметный результат, но не текст ответа или templateId. Для записи сформированного текста не выполняется второй переход FSM.

Уточнение по согласованному ревью кода: `SessionResponseRenderer` используется общим оркестратором для POST и GET, проверяет локальный каталог при старте и заполняет его по снимку. `SessionResponseMapper` собирает проекции по именам полей. Многоаргументные позиционные конструкторы и скрытое дописывание входного DTO заменены возвращающими новый объект mapper-методами; одноразовое создание снимка допускает именованный Lombok builder. Вид успеха/отказа закреплён кодом, а не редактируемым текстовым ресурсом.

Уточнение от 05.10.2026: код ACL-агента, выбор каталога ответов и формат отображения даты задаются в application.yaml без дублирующих значений по умолчанию в Java. Настройки подключений, имени corr и транспортных тайм-аутов также принадлежат YAML. Версия ACL, ключи внешнего/сохранённого формата и бизнес-события остаются контрактом кода, а не переменными окружения.

Ошибка Action сначала откатывает транзакцию, затем оркестратор формирует содержание ошибки, а адаптер — wire-ответ. Сбой форматирования/отправки после commit не откатывает операцию и не запускает её повторно. GET использует тот же принцип подготовки ответа из полученного снимка.

## Проверка и дальнейшие этапы

Сквозной тест подтверждает финальный ACL-ответ по [ADR-018](0018-first-stage-acl-profile.md). Review проверяет отсутствие generated ACL DTO, текстов и templateId в FSM/Actions.

Для будущих зарегистрированных шаблонов GA представление выбирается оркестрацией, а wire-поля — адаптером по согласованному внешнему контракту. Это не основание заранее вводить платформенный реестр шаблонов в POC. Прежнее требование атомарно сохранять с FSM готовый внешний ответ заменено сохранением **предметного результата** по [ADR-009](0009-atomic-transition-commit.md).
