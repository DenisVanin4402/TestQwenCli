# ADR-016. Spring Data JPA и явные блокировки

**Статус:** Принят. **Редакция:** 04.10.2026.

## Решение

Прикладные DB-операции выполняются через конкретные Spring Data JPA repositories с необходимыми методами, без ручного EntityManager и универсального собственного слоя репозиториев. Репозитории и JPA entities остаются внутри DB-реализации; вызывающий код получает внутренние DTO.

Блокировка задаётся у метода запроса: для изменяющего хода — PESSIMISTIC_WRITE и запрос на отсутствие ожидания через jakarta.persistence.lock.timeout=0, для согласованного GET — PESSIMISTIC_READ. На целевой PostgreSQL фактический SQL должен соответствовать FOR UPDATE NOWAIT/FOR SHARE NOWAIT по [ADR-010](0010-session-execution.md). При необходимости используется конкретный native query; наличие hint само по себе не доказывает семантику выбранного провайдера/БД.

Создание постоянного семафора выполняется отдельной короткой транзакцией, завершённой до рабочей. Захват, восстановление FSM, synchronous transition Action и native save выполняются в общей рабочей JPA-транзакции. Временный сетевой вызов WorkflowManager находится внутри неё по [ADR-009](0009-atomic-transition-commit.md). Прежнее безусловное правило «сеть вне транзакций» здесь заменено явно принятым временным допущением.

Штатный persister SSM и его штатный репозиторий сохраняются. Внутренняя реализация сторонней библиотеки с EntityManager не требует её переписывания и не означает разрешения собственного параллельного checkpoint-store.

Общий node lock, порядок executor-before-session, владельцы, токены и журналы старого протокола не входят в новое решение. Дополнительные SessionStore-обёртки не создаются, если они лишь дублируют уже имеющуюся прикладную DB-границу.

## Проверка

Проверяются сохранение/чтение, совместный rollback прикладных и native-данных, реальные конфликты блокировки PostgreSQL и повторная инициализация после сбоя. H2 допускается по [ADR-003](0003-h2-persistence-and-runtime.md), но не доказывает NOWAIT целевой БД. Достаточны проверки реального поведения по [ADR-017](0017-spring-http-and-database-acceptance.md); тесты порядка удалённых owner/token-проверок не сохраняются.
