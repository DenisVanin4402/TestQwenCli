Владельцем контракта является команда Контент коммуникаций: AI Proxy. Актуальная версия доступна [по ссылке](/pages/viewpage.action?pageId=23057177590)

ППРБ GigaAssistant вместе с сообщением пользователя уже передает всем агентам следующий перечень атрибутов: **epk\_id**, **digital\_id**, **sfl\_epk\_id**, **digital\_user\_id**, **efs\_session**, **sbbol\_csrf\_token**, **efs\_token, mobile\_app\_version, os, surface.type, surface.code**

![(звезда)](/s/o4vlaz/8804/1jpfuow/_/images/icons/emoticons/star_yellow.svg) Для получения других параметров пользователя требуется интеграция с [Сервисом получения сессионных данных GigaAssistant для ИИ-агентов](/pages/viewpage.action?pageId=20169172656)

Агент должен поддерживать обратную совместимость контрактов. Добавление новых полей в запросе не должно влиять на логику агента.

## Ключевые требования к ответам от агентов

-   COMMON
    | **Код** | **Логика агента** | **Действие на стороне GA** |
    | --- | --- | --- |
    | **200 успешный ответ** | Агент отправляет ответ | Ответ транслируется пользователю |
    | **202-1** Вопрос направлен не на того агента (ошибка оркестрации) | Агент сверяет, что направленный запрос соотносится с тематиками, на которые он может ответить<br>Если тематики не сходятся - агент отправляет данный код<br>Агент получает явный запрос на работу с оператором | При получении этого статус кода Giga-ассистент проведет переклассификацию запроса на другого агента |
    | **202-2** Агент еще не научился отвечать на данный вопрос | Агент понимает, что вопрос находится в его домене, однако он не может предоставить качественный ответ | При получении этого статус кода Giga-ассистент проведет переклассификацию запроса на другого агента |
    | **202-5** Агент просит подключить оператора | Агент понимает, что для дальнейшего обсуждение необходимо подключение специалиста | При получении этого статус кода Giga-ассистент выведет сообщение с возможностью перейти на форму работы с оператором |

    | **400-2** Ошибка в параметрах запроса на агента | Агент определил, что ему не хватает параметров для работы | При получении этого статус кода Giga-ассистент проведет переклассификацию запроса на другого агента |
    | **500-2** Непредвиденная ошибка на агенте | Агент получил ошибку | При получении этого статус кода Giga-ассистент проведет переклассификацию запроса на другого агента |
