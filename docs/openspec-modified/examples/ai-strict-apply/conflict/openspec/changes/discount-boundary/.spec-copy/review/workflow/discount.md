# Скидка на заказ

## Условие предоставления

<p style="color:#b42318;background-color:#fee4e2;padding:2px 5px;border-left:4px solid #d92d20;border-radius:4px;"><strong style="font-size:10px;margin-right:10px;">−</strong> <del>Если сумма заказа &gt; 10000 рублей, предоставляется скидка 5%.</del></p>

<p style="color:#067647;background-color:#dcfae6;padding:2px 5px;border-left:4px solid #079455;border-radius:4px;"><strong style="font-size:10px;margin-right:10px;">+</strong> Если сумма заказа &gt;<span style="background-color:#abefc6;color:#054f31;font-weight:700;">=</span> 10000 рублей, предоставляется скидка 5%.</p>

Иначе скидка не предоставляется.

## Порядок расчёта

Сумма заказа определяется до применения скидки.
Скидка рассчитывается один раз для всего заказа.

## Максимальная скидка

Максимальная сумма скидки составляет 1000 рублей.
