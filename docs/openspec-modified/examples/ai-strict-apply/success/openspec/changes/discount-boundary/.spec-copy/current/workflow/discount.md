# Скидка на заказ

## Условие предоставления

Если сумма заказа > 10000 рублей, предоставляется скидка 5%.
Иначе скидка не предоставляется.

## Порядок расчёта

Сумма заказа определяется до применения скидки.
Скидка рассчитывается один раз для всего заказа.

## Максимальная скидка

Максимальная сумма скидки составляет 1500 рублей.
