# Исторический пример — алгоритмический apply отменён

Этот пример относится к прежнему подходу, от которого отказались: diff-блоки для аналитика и автоматическое слияние Python/Git. Сохранённые `generated/` и execution/receipt — исторические артефакты, их нельзя выдавать за результат AI apply.

**Актуальный пример:** [обычный discount.md с цветными правками и строгий AI apply после merge релиза](../ai-strict-apply/README.md).

Исполняемый `run_example.py` и прежний `spec_copy.py` удалены. Работа продолжается через skill `openspec-apply-change` с `Apply policy: ai-strict`. Содержание старых снимков и receipts не переписано.
