Это учебный пример на изолированных документах.

## Цель

Предоставлять скидку 5% также при сумме заказа ровно 10000 рублей.

## Изменение

| ID | Было → стало | Копия для ревью |
|---|---|---|
| CH-01 | Сумма > 10000 → сумма >= 10000 | [Правило скидки](.spec-copy/review/D001.md) |

## Критерии приёмки

| Сумма заказа | Ожидаемая скидка |
|---|---|
| 9999 | Нет |
| 10000 | 5% |
| 10001 | 5% |
