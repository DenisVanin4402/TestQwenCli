# Review архитектуры этапа 2

05.10.2026, редакция после перехода на ACL-чат. Выполнено оркестратором.

- Agent-ui содержит ленту сообщений, composer и клиентскую доставку. Пользовательские ходы идут только в LocalAclController из agent-ui-back и общий AclInputAdapter.
- AclMapper выдаёт suggestions после отказа и propose/state CONFIRMATION для сводки. Тот же метод initialSuggestions используется каталогом fixtures. Generated-типы получены из общей схемы YAML; код generated не редактируется.
- GET сессии, его wire-модели, LocalHelperAdapter и SessionViewMapper удалены. FixtureMapper обслуживает только каталог. Внутреннее чтение для проверки сохранения не является HTTP API.
- Браузер не знает availableCommands и FSM-состояний. Propose управляет кнопками согласия; final_message запрещает новые действия. Старые кнопки удаляются, повторный клик и чужая корреляция отклоняются.
- После перезагрузки открывается новый диалог. После потери ответа нет повторов и дополнительных GET. Новый диалог не отменяет предыдущую операцию.
- Свободный текст пока не отправляется. Вывод через textContent не исполняет HTML. Только poc-local публикует каталог, зеркало и экран.

Границы: выбран локальный propose-профиль YAML/1.5 по ADR-020; неполнота таблицы 1.6 и отсутствие регистрации шаблонов GA не скрываются. Инструмент браузера снова вернул пустой список, поэтому визуальная приёмка остаётся непроверенной.
