## Принятые ограничения

- Запрет справки после завершения только клиентский по решению пользователя; прямой ACL-запрос в COMPLETED не блокируется.
- Семантическая оценка ответов ручная. Maven не проверяет смысл поля `expectation`; отдельного LLM-судьи нет. Десять примеров не дают статистической гарантии качества.
- Банковская интеграция в браузерном smoke — stub; подключение настоящей поверхности GA не проверялось. Предыдущие task01/02/04 этим заключением автоматически не закрываются.
- Сохранённые кнопки отображаются под последним сообщением. По последнему указанию пользователя новый сценарий «Продолжить предыдущую операцию — Да / Нет» выполняется отдельной доработкой и не блокирует task05.
