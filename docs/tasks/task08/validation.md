# task08 — Независимая архитектурная валидация

**Дата:** 07.10.2026. Проверка выполнена отдельным агентом по AGENTS.md. Сопоставлены [архитектура](arch_design.md), [согласованный дизайн](impl_design.md), [план](tasks.md), ADR-007/020, текущие изменения и фактические результаты проверок.

**Вывод:** валидация пройдена. Существенных расхождений с принятым вариантом B, лишних механизмов и незакрытых обязательных проверок task08 не выявлено.

## Соответствие решения

- [Provider](../../../agent-api-out/src/main/java/ru/sberbank/pprb/agent/gigachat/GigaChatReferenceAnswerProvider.java) передаёт полный UTF-8 ресурс без каталога и разбора заголовков. Проверяются самостоятельные полные метки `KB-[0-9]+`; KB-00 и повторные упоминания в знаниях допустимы. `sourceIds` обязательны для найденной справки; пустой список преобразуется в отсутствие сведений. Строгий JSON, различие отсутствия сведений и технического сбоя, единственная попытка сохранены.
- [Промпт](../../../agent-api-out/src/main/resources/config/gigachat-prompts.yaml) содержит общие правила, [знания](../../../agent-api-out/src/main/resources/knowledge/status-reference.md) — операции и банковские условия. Каталог исполняемых команд остаётся у классификатора в [оркестраторе](../../../agent-service/src/main/java/ru/sberbank/pprb/agent/service/turn/SessionTurnOrchestrator.java). Новых загрузчиков, поиска, синхронизации каталога или повторной генерации нет.
- [Renderer](../../../agent-service/src/main/java/ru/sberbank/pprb/agent/service/turn/SessionResponseRenderer.java) выбирает прежнюю фразу INVALID_COMMAND только для INTERMEDIATE; после отмены отказ нейтрален. Новый шаблон проверяется при создании renderer. Навигация, согласие, FSM, persistence и внешний ACL не менялись. В промышленном Java-коде `var` не обнаружен.
- ADR, индекс и затронутые документы этапов/task07 явно отражают область замены; прежняя браузерная приёмка не объявлена выполненной.

## Ограничения

Наличие метки подтверждает источник по контракту, а не достоверность каждой формулировки модели; смысл проверен на согласованных сценариях. Браузерная приёмка task07 остаётся отдельной открытой задачей и данной валидацией не закрывается. Успешные тесты без новых изменений повторно не запускались.
