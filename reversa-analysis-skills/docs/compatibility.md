# Совместимость и основания решений

[К началу](../README.md) · Проверено по документации 6 сентября 2026 года.

## Общее ядро

Каждый навык — папка с SKILL.md, краткими метаданными `name`/`description` и ссылками на ресурсы. Имена написаны латиницей с дефисами, инструкции и описания — на русском. Это общее подмножество [Agent Skills](https://agentskills.io/specification). Мы не используем в общем ядре специфичные поля назначения подагента, ограничения инструментов, подстановку аргументов или динамические shell-вставки.

| Среда | Проектный каталог | Подключение | Проверка этой поставки |
|---|---|---|---|
| Codex с GPT | `.agents/skills/` | Выбор навыка или `$reversa-analysis` | Формат, файловая установка и локальные помощники проверены |
| Claude Code | `.claude/skills/` | `/reversa-analysis` | Формат и копирование проверены; поведенческая сессия не выполнена |
| Qwen Code | `.qwen/skills/` | `/skills` или запрос применить навык | Формат и копирование проверены; поведенческая сессия не выполнена |
| Иная агентская среда | Её каталог либо общий доступ к распакованному набору | Прочитать SKILL.md и связанные ресурсы | Требуется проверка загрузчика конкретной среды |

Codex документирует проектный каталог `.agents/skills`, имена/описания для выбора и явный вызов навыков. Дополнительное оформление `agents/openai.yaml` необязательно; для общего ядра оно не требуется. [Официальная документация OpenAI](https://learn.chatgpt.com/docs/build-skills).

Claude Code документирует `.claude/skills` и вызов по имени. Qwen Code документирует `.qwen/skills` и список `/skills`. Эта поставка использует одинаковые файлы в соответствующих каталогах. [Claude Code](https://code.claude.com/docs/en/skills), [Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/users/features/skills/).

## Reversa

Проверенная опора — Reversa 1.3.2, commit 57165e2d5ff1d5b754ba8b73a24a3c188b5f68a8. В его наборе `reversa-docs` координирует создание HTML по уже извлечённым материалам. Здесь используется самостоятельный набор навыков для предметной Markdown-аналитики; интеграция идёт через чтение артефактов. Поставляемые команды и шаблоны Reversa не заменяются. [Исследованная редакция Reversa](https://github.com/sandeco/reversa/tree/57165e2d5ff1d5b754ba8b73a24a3c188b5f68a8).

## Предел переносимости

Инструкции, шаблоны и Node-помощники не зависят от модели. Это не гарантирует одинаковое качество анализа у разных моделей или поддержку произвольным загрузчиком навыков. Для проверки новой среды используйте одинаковый сырой учебный источник, одинаковый запрос и [критерии результата](validation.md); отдельно отмечайте различия в качестве, инструментах и соблюдении границ.
