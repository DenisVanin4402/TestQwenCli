# Установка и обновление

[К началу](../README.md)

## Установка в проект

Команды выполняются из корня распакованного набора. Укажите существующий каталог нужного проекта. Установщик меняет только каталоги навыков и собственный реестр установки внутри них.

```text
node bin/install.mjs --project "../my-project" --agent codex
node bin/install.mjs --project "../my-project" --agent codex --apply
```

Замените `codex` на `claude`, `qwen` или `all`. В PowerShell можно указать абсолютный путь вида `C:/Projects/my-system`. Параметр `generic` использует `.agents/skills`; автоматическое обнаружение этого каталога другим агентом нужно проверить в его документации.

В каждой выбранной среде устанавливаются **все семь навыков** соседними папками. Самостоятельная копия одного специализированного SKILL.md недостаточна: он использует шаблоны и стандарт основного навыка.

## Проверка подключения

- Codex: выберите `$reversa-analysis` или найдите его через `/skills`.
- Claude Code: вызовите `/reversa-analysis`.
- Qwen Code: откройте `/skills`, выберите навык или попросите применить `reversa-analysis`.
- Если среда не подхватила новые файлы, обновите список навыков или перезапустите её согласно документации.

Запросите создание небольшой аналитики на [учебном источнике](../examples/library-lending/sources/policy.md) или ограниченной capability своего проекта. Не считайте появление имени в списке проверкой качества результата.

## Обновление

```text
node bin/install.mjs --project "../my-project" --agent all --update
node bin/install.mjs --project "../my-project" --agent all --update --apply
```

Реестр `.reversa-analysis-install.json` хранит хэши установленных файлов. Обновляются только файлы, которые не менялись после предыдущей установки. При конфликте команда с `--apply` останавливается до записи в любой выбранный каталог. Разберите diff и перенесите нужные правки в новую версию вручную; флага принудительного перезаписывания нет. Устаревшие файлы автоматически не удаляются.

Проверка конфликтов не обеспечивает транзакцию файловой системы при сбое диска или конкурентном редактировании во время записи. Выполняйте установку после завершения редактирования навыков; обычные средства контроля версий помогают проверить результат.

## Ручной перенос и работа без установки

Можно скопировать содержимое `skills/` целиком в нужный каталог навыков, сохранив имена и соседство семи папок. При ручном переносе установщик не управляет обновлением этих файлов, если их версии отличаются от поставки.

Для разовой работы дайте агенту абсолютный путь к основному SKILL.md в распакованном наборе и доступ ко всем соседним папкам. В агенте без навыков загрузчик должен прочитать этот файл и выдавать дополнительные ресурсы по ссылкам; специальный синтаксис slash-команды не обязателен.

Если агент изолирует ресурсы каждого навыка, подключите весь набор в общий доступный каталог либо адаптируйте упаковку с включением общих ресурсов. Эта поставка рассчитана на совместное файловое дерево; она не объявлена готовым пакетом для произвольного API загрузки отдельных изолированных навыков.

## Отношение к прежнему пилотному профилю

Этот набор развивает подход одиночного `reversa-system-analysis`. Пилотные документы можно продолжать использовать; новый валидатор поддерживает их реестры версии 1. Старый профиль и документы автоматически не удаляются и не заменяются. Для новых задач используйте выбранный набор последовательно, чтобы не загружать две разные редакции стандарта одновременно.
