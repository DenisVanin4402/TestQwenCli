## Что проверяют инструменты

`check-suite.mjs` проверяет общее подмножество метаданных, наличие ресурсов и локальных ссылок, JSON и учебный пакет. Это не общий YAML-парсер. При выпуске SKILL.md дополнительно проверяются штатным `quick_validate.py` из навыка skill-creator в среде автора; он не входит в переносимую зависимость набора.

`validate` проверяет IDs, родителей, пути, разделы, локальные ссылки и якоря, вопросы, основания и формальные условия статусов, вложения и существование целей трассируемости. Он не проверяет грамматику Mermaid, полную семантику Markdown/MDX, доступность сетевых ссылок, подлинность согласования и предметную корректность.

Тесты установки доказывают поведение локального установщика, но не выполнение задач моделью в соответствующей среде. Полноценные сессии генерации через Qwen Code и Claude Code этой поставкой ещё не выполнены. Качество нового домена проверяйте на ограниченном пилоте перед расширением области.

## Поведенческий критерий

Результат новой среды должен сохранять факты входного источника, явно отражать неизвестности, не вводить неподтверждённые возможности и обеспечивать навигацию и проверяемые исходы. Читатель должен пройти сценарий без исходного кода. Структурный успех без этих свойств не считается достаточным качеством аналитики.
