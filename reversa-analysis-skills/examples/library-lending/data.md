> ENT-002 · Учебная спецификация TO-BE · Вымышленная предметная область · Черновик

<a id="rsa-назначение"></a>
## Назначение

Определить данные проверки и результата.

<a id="rsa-сущности-и-атрибуты"></a>
## Сущности и атрибуты

| Атрибут | Тип и смысл | Ограничение |
|---|---|---|
| Состояние читателя | Действующий / заблокированный | Обязательно для решения |
| Число действующих выдач | Целое количество | От 0; до новой выдачи меньше 3 |
| Доступность экземпляра | Свободен / выдан | Новый запрос допустим для свободного |
| Дата выдачи | Календарная дата | Обязательна |
| Дата возврата | Календарная дата | Рассчитывается по ALG-001 |

<a id="rsa-связи-и-инварианты"></a>
## Связи и инварианты

Выдача связывает выбранных читателя и экземпляр. Не следует считать число выдач количеством уникальных книг во всей истории.

<a id="rsa-неизвестные-условия"></a>
## Неизвестные условия

Формат внешнего сообщения, ошибка отсутствующего поля и проверки идентификаторов не определены учебной политикой; не входят в реализуемый контракт этого примера.
