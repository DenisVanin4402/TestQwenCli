> REQ-001 · Учебная спецификация TO-BE · Вымышленная предметная область · Черновик

<a id="rsa-назначение"></a>
## Назначение

Требования TO-BE вымышленного примера.

<a id="rsa-правила"></a>
## Правила

| ID | Требование |
|---|---|
| <a id="fr-001"></a>FR-001 | Допускать выдачу только действующему читателю с менее чем 3 выдачами и для свободного экземпляра |
| <a id="fr-002"></a>FR-002 | При успехе создавать выдачу с датой возврата по ALG-001 |
| <a id="fr-003"></a>FR-003 | При отказе сохранять прежнее состояние без новой выдачи |

<a id="rsa-исключения-и-расхождения"></a>
## Исключения и расхождения

FR-002 ограничен Q-001; FR-001 — Q-002 в части выбора причины сообщения. Эти вопросы не решены автоматически.
