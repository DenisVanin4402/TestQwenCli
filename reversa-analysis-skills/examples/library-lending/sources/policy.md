# Учебная политика выдачи экземпляра

Полностью вымышленный пример; не сведения о существующей библиотеке. Версия 1.

1. Библиотекарь выдаёт читателю один доступный экземпляр. Читатель может быть действующим или заблокированным. Заблокированному читателю выдача запрещена.
2. У читателя допускаются не более трёх действующих выдач. Если до операции их уже три, новая выдача отклоняется.
3. Один экземпляр может иметь не более одной действующей выдачи. Занятый экземпляр выдавать нельзя.
4. Если все три ограничения соблюдены, создаётся действующая выдача. Дата возврата равна календарной дате выдачи плюс 14 календарных дней. Даты не содержат время суток; часовой пояс в этом примере не нужен.
5. При отказе новая выдача не создаётся и экземпляр не меняет состояние. При успехе экземпляр становится выданным.
6. Учёт возврата, штрафы, продление и резервирование не входят в этот пример. Перенос срока при нерабочем дне не определён. Порядок сообщения нескольких одновременных причин отказа не определён.
