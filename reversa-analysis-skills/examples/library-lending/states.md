<a id="rsa-назначение"></a>
## Назначение

Показать изменение доступности только при выдаче.

<a id="rsa-состояния"></a>
## Состояния

Свободен — нет действующей выдачи. Выдан — действует выдача экземпляра.

<a id="rsa-переходы"></a>
## Переходы

```mermaid
stateDiagram-v2
  state "Свободен" as Free
  state "Выдан" as Loaned
  Free --> Loaned: Успешная выдача
  Free --> Free: Отказ по условиям читателя
  Loaned --> Loaned: Новая выдача отклонена
```

<a id="rsa-ограничения"></a>
## Ограничения

Обратный переход выполняется процессом возврата, который не описан в примере. Не добавляем его условия предположением.
