# Markdown, Mermaid и навигация


Вход — существующие предметные документы и реестры. Сборка не должна менять их смысл. Прочитай [контракт](../reversa-analysis/references/package-contract.md), [правила диаграмм](../reversa-analysis/references/diagrams.md) и [команды](../reversa-analysis/references/commands.md).

## Результат

- README с назначением, областью и статусом, маршрутами чтения и деревом документов.
- Оглавление каждой страницы, переход к родителю и корню; относительные ссылки внутри переносимого пакета.
- Mermaid внутри соответствующего Markdown: модель, процессы, алгоритмы и состояния. Таблицы содержат точные ограничения, которые схема не выражает.
- Устойчивые ID и якоря для FR/BR/AC/Q; матрица связывает требование с подробным описанием и проверкой.
- Отдельное приложение с доказательствами, решениями, вопросами и фактическими результатами проверки.

Для навигации сначала запусти nav без записи, проверь список затронутых страниц, затем используй --write в уже разрешённой области. Повторный запуск должен быть идемпотентным. Команда управляет только своими блоками и якорями rsa-; ручной текст и исходные ID сохраняются. Отредактируй сам README по [шаблону](../reversa-analysis/assets/templates/overview.md): дерево генерируется, содержательные маршруты определяет агент.

## Проверка и передача

Проверь validate, наличие вложений и Mermaid-рендер. Просмотри длинные подписи и широкие схемы, при необходимости измени направление или раздели схему без добавления новых связей. Код рендера и временные картинки не являются основной спецификацией.

Архивируй только зарегистрированные документы, реестры и нужные вложения с сохранением структуры каталогов. Абсолютные ссылки технических источников в evidence могут быть непереносимыми; основные страницы должны читаться без них. Не включай секреты, исходный проект целиком или пользовательскую историю в демонстрационный архив навыков.

Для Confluence подготовь соответствие ID → страница и список преобразуемых ссылок/Mermaid-блоков. Публикация выполняется отдельной авторизованной операцией через доступные средства пространства. Не обещай поддержку Mermaid любым редактором Confluence. Итоговый формат по умолчанию — Markdown; HTML создаётся только как отдельно запрошенное представление.
