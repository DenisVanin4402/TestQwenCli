# Локальные команды

Требуется Node.js 18.20 или новее, сторонних зависимостей нет. Команды одинаковы в PowerShell, Bash и других оболочках; пути с пробелами заключай в кавычки. Ключи ниже принадлежат нашим помощникам, а не CLI Reversa.

Из корня распространяемого набора:

~~~text
node bin/analysis.mjs inspect --project "ПУТЬ_ПРОЕКТА"
node bin/analysis.mjs init --output "ПУТЬ_ПАКЕТА" --system "Имя системы" --baseline "Версия источников"
node bin/analysis.mjs nav --package "ПУТЬ_ПАКЕТА"
node bin/analysis.mjs nav --package "ПУТЬ_ПАКЕТА" --write
node bin/analysis.mjs validate --package "ПУТЬ_ПАКЕТА"
node bin/analysis.mjs impact --package "ПУТЬ_ПАКЕТА" --source-root "ПУТЬ_ИСТОЧНИКОВ"
~~~

После установки вместо bin/analysis.mjs укажи scripts/cli.mjs внутри установленного основного навыка. Вывод — JSON; ошибка завершает команду ненулевым кодом. --strict у validate считает предупреждения причиной неуспеха, но не усиливает содержательную проверку.

| Команда | Запись | Назначение и предел |
|---|---|---|
| inspect | Нет | Инвентаризация материалов; не извлечение требований |
| init | Только выбранная пустая/новая папка | Начальная структура с явно открытым вопросом; не готовая аналитика |
| nav | Только с --write | Управляемые блоки навигации и якоря; не меняет смысл и статусы |
| validate | Нет | Структура, ссылки, источники/статусы и трассируемость; без Mermaid-парсера |
| impact | Нет | Сравнение хэшей и кандидаты для ревью; недоступность не считается удалением функции |

Если Node недоступен, прочитай шаблоны и выполни преобразование средствами агента; сообщи, что автоматический валидатор не запускался. Не утверждай, что helper создал аналитику сам. Для Mermaid используй доступный редактор/рендерер и фиксируй версию и результат; установка внешних зависимостей не является обязательной частью навыка.
