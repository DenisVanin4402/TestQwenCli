# Материалы Reversa

Проверенная опора — локально исследованный Reversa 1.3.2, commit 57165e2d5ff1d5b754ba8b73a24a3c188b5f68a8. Другие версии могут иметь иные имена и расположение артефактов; проверяй фактические файлы. Набор не устанавливает и не запускает Reversa автоматически.

| Материал | Что извлечь | Ограничение |
|---|---|---|
| .reversa/state.json | Папка выходных материалов, состояние работы | Наличие статуса не заменяет проверки документа |
| soul.md, domain.md, architecture.md в выходной папке либо соответствующие материалы .reversa | Назначение, понятия, границы и связи | Имена зависят от версии и конфигурации |
| requirements.md / design.md / tasks.md по областям | Поведение, правила, данные, открытые задачи | Область Reversa не обязана совпадать с capability |
| review-decisions.md и относящиеся записи решений | Принятые направления и точные ответы | Направление может быть принято, но не реализовано |
| Дополнения и исправления после ревью | Уточнения исходного извлечения | Читать вместе с первоначальной редакцией |
| Адресно выбранная исходная логика и тесты | Проверка формул, порогов, ветвей, внешних гарантий | Прочитанный тест не является выполненным |

Вызов inspect выводит пути и хэши материалов .reversa и выходной папки, включая output_folder из state.json внутри проекта. Не считай его полным сканером исходников. Выбирай и регистрируй только использованные источники; содержимое файлов читается по необходимости.

Не перезаписывай шаблоны Writer и результаты Reversa ради другой иерархии. Этот набор формирует отдельный читательский слой. Если старые инструкции проекта ограничивают пути записи, выбери разрешённый выходной каталог, например отдельную подпапку в разрешённом дереве; не переписывай инструкции для обхода ограничения.

Пользовательские интервью, документы и ручные процедуры допустимы наравне с материалами Reversa. Если вход — только TO-BE-требования, прямо укажи, что наблюдаемая реализация не исследовалась.
